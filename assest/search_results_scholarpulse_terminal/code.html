Attention Is All You Need

The dominant sequence transduction models are based on complex recurrent or convolutional neural networks. We propose the Transformer, a model architecture eschewing recurrence and instead relying entirely on an attention mechanism to draw global dependencies between input and output.

FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness

Transformers are slow and memory-hungry on long sequences, as the time and memory complexity of self-attention are quadratic in sequence length. We propose FlashAttention, an IO-aware exact attention algorithm that uses tiling to reduce the number of memory reads/writes between GPU HBM and GPU SRAM.

T. Dao · D. Fu · S. Ermon · A. Rudra · C. Ré Stanford SAIL

Rethinking Attention with Performers

Recent advances in Transformer architectures have shown impressive performance, but scaling to long inputs is hindered by the quadratic cost. We introduce Performers, Transformer models capable of provably approximating regular softmax attention mechanisms with linear space and time complexity using Fast Attention Via positive Orthogonal Random features (FAVOR+).

K. Choromanski · V. Likhosherstov · D. Dohan Google Research Cambridge

Reformer: The Efficient Transformer

Large Transformer models routinely achieve state-of-the-art results, but training them can be prohibitively expensive. We present Reformer, introducing locality-sensitive hashing to replace $O(L^2)$ dot-product attention by $O(L \log L)$.

N. Kitaev · Ł. Kaiser · A. Levskaya UC Berkeley Google Brain
